Quand vous visitez le site

  • Aucun cookie, aucun outil de mesure d'audience, aucune publicité. Les polices de caractères sont hébergées sur le site lui-même.
  • Le site est hébergé par GitHub, Inc. (service GitHub Pages), aux États-Unis. Comme tout hébergeur, GitHub reçoit l'adresse IP des visiteurs et peut la garder dans ses journaux pour la sécurité du service. Il s'agit d'un transfert de données hors de l'Union européenne, encadré par la déclaration de confidentialité de GitHub.
  • Les pages État du service et Références peuvent lire des fichiers publiés sur GitHub (raw.githubusercontent.com), avec les mêmes conditions.
  • Si vous cliquez sur « Avec Gmail » ou « Avec Outlook », vous quittez le site pour Google ou Microsoft, qui appliquent leurs propres règles.

Quand vous m'écrivez ou m'appelez

  • Ce que je garde : votre nom, votre entreprise, vos coordonnées et le contenu de vos messages, ainsi que les documents que vous m'envoyez pour la démonstration.
  • Pourquoi : vous répondre, organiser une démonstration et, si vous le souhaitez, préparer un contrat. Ces données ne sont ni vendues, ni louées, ni utilisées pour de la publicité.
  • Sur quelle base : les mesures préalables à un contrat que vous demandez, et l'intérêt légitime d'Itinéos à répondre aux entreprises qui le contactent.
  • Combien de temps : 3 ans après notre dernier échange si nous ne travaillons pas ensemble. Les documents envoyés pour une démonstration sont effacés à la fin de la démonstration si vous ne donnez pas suite.
  • Où : la messagerie de l'adresse itineos.fr est fournie par IONOS, en Europe.

Quand vous déposez un document pour la démonstration automatique

  • Ce qui est envoyé : le document déposé (fiche d'intervention ou bon de sortie), le nom de votre entreprise et votre e-mail, au serveur d'Itinéos (app.itineos.fr, en France).
  • Pourquoi : reproduire votre fiche dans Itinéos et vous envoyer le lien pour la voir. Le document est lu par l'API de Claude (Anthropic) pour en tirer la fiche.
  • Contre les robots : le formulaire peut utiliser Friendly Captcha (sans cookie). Votre adresse IP n'est gardée que sous forme d'empreinte, pour limiter les envois.
  • Combien de temps : tout est effacé au bout de 30 jours. Pour l'effacer plus tôt, écrivez-moi.
